# 后台管理系统 PRD（练习用）

## 背景

团队需要一个简单的后台，管理员可以管理注册用户，并能追溯谁在什么时候做了什么操作。

注册、登录、退出已经由脚手架提供（Better-Auth 邮箱密码登录，页面在 `/login`），本期只在此基础上扩展。

## 角色

- **普通用户**：可以注册、登录，只能看到自己的个人信息
- **管理员**：可以进入后台，管理所有用户、查看操作日志

第一个管理员通过数据库手动设置（把用户的角色改成管理员），本期不做"设置管理员"的界面。

## 功能 1：后台访问控制

- 后台入口是 `/dashboard`
- 未登录访问 `/dashboard` 及其子页面，跳转到 `/login`，登录成功后回到原来要访问的页面
- 普通用户访问后台，显示"无权限访问"页面，不显示后台内容
- 后台顶部显示当前管理员的名字和邮箱，提供退出按钮

## 功能 2：用户管理

- 页面 `/dashboard/users`，展示用户列表：名字、邮箱、角色、状态（正常 / 已禁用）、注册时间
- 每页 20 条，支持翻页
- 支持按名字或邮箱搜索（模糊匹配，不区分大小写）
- 管理员可以 **禁用** / **启用** 用户：
  - 操作前弹窗确认
  - 被禁用的用户无法登录，登录时提示"账号已被禁用"
  - 被禁用的用户如果当前已登录，下一次请求时退出登录
  - 管理员不能禁用自己
- 列表为空、搜索无结果时显示空状态提示

## 功能 3：操作日志

- 记录以下操作：管理员禁用用户、管理员启用用户
- 每条日志包含：操作人、操作类型、操作对象（被操作的用户）、操作时间
- 页面 `/dashboard/logs`，按时间倒序展示，每页 20 条，支持翻页
- 可以按操作类型筛选
- 日志只能查看，不能修改或删除

## 不做的事

- 第三方登录（GitHub、Google 等）
- 修改用户资料、删除用户
- 设置管理员的界面
- 日志导出
