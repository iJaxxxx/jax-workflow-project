# 操作日志

## 背景
需要追溯哪个管理员在什么时候禁用 / 启用了哪个用户。

## 用户故事
- 作为管理员，我想要查看禁用 / 启用的历史记录，以便追溯是谁做的
- 作为管理员，我想要按操作类型筛选日志，以便只看禁用或只看启用

## 前置条件
- 模块 02 已完成（`user.setBanned`）

## 验收标准
- [ ] AC1：给定管理员禁用了用户 B，那么 `/dashboard/logs` 新增一条记录：操作人 = 当前管理员（名字 + 邮箱）、操作类型 = "禁用用户"、操作对象 = B（名字 + 邮箱）、操作时间 = 刚才
- [ ] AC2：给定管理员启用了用户 B，那么新增一条操作类型为"启用用户"的记录
- [ ] AC3：给定禁用失败（例如尝试禁用自己被拒绝），或对已禁用用户再次禁用（状态没变），那么不产生日志
- [ ] AC4：给定日志超过 20 条，那么按时间倒序显示，每页 20 条，支持翻页，URL 带 `page` 参数
- [ ] AC5：给定选择"禁用用户"筛选，那么只显示禁用记录，并回到第 1 页；选"全部"恢复显示所有记录
- [ ] AC6：给定还没有任何日志或筛选后没有结果，那么显示"暂无操作日志"空状态
- [ ] AC7：给定日志页面，那么没有任何编辑或删除入口；`appRouter` 里不存在修改或删除日志的 procedure
- [ ] AC8：给定普通用户直接调用 `operationLog.list`，那么返回 `FORBIDDEN`

## 不做的事
- 日志导出
- 记录禁用 / 启用以外的操作（例如登录、注册）
- 按操作人、操作对象、时间范围筛选
